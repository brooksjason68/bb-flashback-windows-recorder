## Overview

BB Flashback provides Windows users with a flexible way to create recordings for tutorials, software demonstrations, presentations, and guided walkthroughs. It can capture the desktop, webcam footage, or both at once, allowing the recording process to remain within one application.

Capture can be configured for an entire display, an individual window, or a manually defined area. Once recording is complete, the integrated editor, scheduling tools, keyboard shortcuts, audio mixing controls, and format-specific export options help prepare the final video.

---

## Key Capabilities

- Capture desktop activity, webcam footage, or both simultaneously
- Record a complete display, one application window, or a custom screen area
- Take advantage of hardware-accelerated encoding for smoother capture
- Make changes to recordings with the included editor
- Arrange recordings to begin at a specified time
- Control recording actions through configurable hotkeys
- Combine several audio inputs in one recording
- Produce video files in a range of export formats

## Recording Workflow

To make a recording:

1. Launch BB Flashback.
2. Select the area or source to capture:
   - entire screen
   - one chosen window
   - custom region
3. Turn on webcam and audio inputs where required.
4. Configure recording hotkeys or create a recording schedule.
5. Start capture and stop it once the session is complete.
6. Load the result into the built-in editor for trimming or adjustment.
7. Export the finished recording using the desired format.

Some practical examples include:

- Creating a product demonstration with desktop and webcam video
- Recording a browser window for a tutorial
- Scheduling a capture session for a meeting or other event
